# \[\[=std::interop\]\] An Annotation for Interoperation with Targets

`std::interop` is a proposed C++ annotation that marks a declaration for
exposure to another language or runtime.

The [proposal.pdf][pdf] is the first thing to read, before anything else.

This is the [website](https://whatchamacallem.github.io/proposals/) for the
paper. It provides an index of the outputs generated by the
[repository](https://github.com/whatchamacallem/proposals):

## Proposal Docs

- [proposal.pdf][pdf] : The proposal as a PDF.
- [proposal.html][html] : The proposal as a web page.
- [proposal.latex][latex] : LaTeX source.

## Interop Generator

- [interop.h][h] [[raw][h-raw]] : The code from the paper.
- [interop.cpp][cpp] [[raw][cpp-raw]] : A reference code generator.

## Generated Per-Language Files

- [interop_generated.cpp][c] [[raw][c-raw]] : The `extern "C"` shim.
- [interop_generated.rs][rs] [[raw][rs-raw]] : The Rust binding.
- [interop_generated.py][py] [[raw][py-raw]] : The Python binding, using
  `ctypes`.
- [interop_generated.js][js] [[raw][js-raw]] : The Node.js binding, using
  `koffi`.

## Test Results

- [tap_protocol.txt][tap] [[raw][tap-raw]] : TAP v14 test results for all the
  languages.
