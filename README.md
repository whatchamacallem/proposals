# \[\[=std::interop\]\] An Annotation for Interoperation with Targets

## Introduction

This paper proposes `[[=std::interop]]`, a standard annotation marking a
declaration for exposure to a foreign execution environment. The annotation
has no effect on the program, and the meaning of target names is left
unspecified. A reference code generator is provided for a number of languages.

The [proposal.pdf][pdf] is the first thing to read, before anything else.

Here is the [website](https://whatchamacallem.github.io/std_interop/) for the
outputs. It provides an index of the files generated by the
[repository](https://github.com/whatchamacallem/std_interop):

## Proposal Docs

- [proposal.pdf][pdf] : The proposal as a PDF.
- [proposal.html][html] : The proposal as a web page.
- [proposal.latex][latex] : LaTeX source.

## Code Generator

- [interop.hpp][hpp] [[raw][hpp-raw]] : The code from the paper.
- [interop.cpp][cpp] [[raw][cpp-raw]] : A reference code generator.

## Generated Per-Language Files

- [interop_generated.h][h] [[raw][h-raw]] : The shim's C header.
- [interop_generated.cpp][c] [[raw][c-raw]] : The `extern "C"` shim.

- [interop_generated.py][py] [[raw][py-raw]] : The Python binding, using
